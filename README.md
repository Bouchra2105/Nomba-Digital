## 🚀 Déploiement sur Vercel

Pour déployer le projet sur Vercel, vous avez deux méthodes simples au choix :

### Méthode 1 : Via le Dashboard Vercel & Git (Recommandée)

1. Publiez ce projet sur votre compte GitHub / GitLab.
2. Rendez-vous sur [https://vercel.com/new](https://vercel.com/new).
3. Connectez votre compte Git et importez le dépôt.
4. Laissez la configuration par défaut (*Other* / Static Site).
5. Cliquez sur **Deploy**.

Votre site sera directement en ligne avec HTTPS et CDN global.

---

### Méthode 2 : Via Vercel CLI (Ligne de commande)

1. Installez Vercel CLI : `npm i -g vercel`
2. Exécutez : `vercel`
3. Déployez en production : `vercel --prod`

---

## 🛠️ Structure du Projet

- `index.html` : Fichier principal contennant la plateforme responsive et interactive.
- `assets/` : Dossier des visuels et logos.
- `vercel.json` : Configuration des routes pour Vercel.
